## Featured Projects

### 1. FITTIN | Biometric & Nutrition Engine

A hybrid machine learning and optimization app that classifies a user's body profile and builds a daily meal plan with exact serving sizes.

I trained a Random Forest model to classify BMI categories, using SMOTE to handle class imbalance. I also used K-Means to group foods by their macronutrient profile, then ranked them by micronutrient density. The app calculates BMR and TDEE, then works out portions that match the user's goal, whether that's a cut, a bulk, or maintenance.

**Tech Stack:** Python, Pandas, NumPy, Scikit-learn, Streamlit, K-Means

[Live Application](https://fittin-b8fjdspvsosvbjwzy6jjxr.streamlit.app/)

---

### 2. ScholarIQ | Student Performance Prediction

An end-to-end machine learning app that predicts a student's mathematics score from academic and demographic information.

This was the project where I learned that a model is only one part of the job. I built a modular pipeline covering data ingestion, transformation, training, and prediction. I compared eight regression algorithms, tuned them with GridSearchCV and 4-fold cross-validation, and saved the model and preprocessor so the app could reuse them. I then deployed it on Render, which taught me a lot about what a project needs in order to work outside my own laptop.

**Tech Stack:** Python, Pandas, NumPy, Scikit-learn, Flask, Dill

[Live Application](https://scholariq-rzps.onrender.com/)

---

### 3. Career Guidance System | Machine Learning Internship Project

A web application that predicts a suitable tech career path for a student based on their skills, interests, and academic performance.

I built this during a college-organized online internship. I trained Random Forest and XGBoost models, saved them as artifacts, and connected them to a Streamlit interface, so a user can enter their profile and get a prediction in the browser.

**Tech Stack:** Python, Pandas, Scikit-learn, XGBoost, Streamlit

[GitHub Repository](https://github.com/dhanrajkandpal/Career-Guidance-System) · [Live Application](https://dhanrajkandpal-career-guidance-system-app-dnvdqb.streamlit.app/)
